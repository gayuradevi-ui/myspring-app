docker tag gayathri-wallet-app:latest gcr.io/cybernetic-pact-417810/gayathri-wallet-app:latest

🏁 STEP 3: DEPLOY TO CLOUD RUN (1-2 minutes)

Run this command:
───────────────────────────
gcloud run deploy gayathriwalletdb-dev \
  --image gcr.io/cybernetic-pact-417810/gayathri-wallet-app:latest \
  --region asia-south1 \
  --platform managed \
  --allow-unauthenticated \
  --set-env-vars "SPRING_PROFILES_ACTIVE=dev"

Expected: Service URL returned ✅

🆘 IF SOMETHING GOES WRONG
════════════════════════════════════════════════════════════════════════════

Build fails?
  Check: java -version (needs 17+)
  Try: .\mvnw.cmd clean install -DskipTests

Docker fails?
  Check: docker --version
  Try: Start Docker Desktop

Push fails?
  Try: gcloud auth configure-docker

Deploy fails?
  Check: gcloud config get-value project
  View: gcloud run logs read gayathriwalletdb-dev --region asia-south1 --limit 50

Still getting 302?
  Check: Using correct endpoint /v1/wallet/register (not /regist)
  Check: Deployed the latest version
  Try: gcloud run deploy again with --force-on-demand flag
